# Teste xUnit com SQL Server

Projeto demonstrativo de testes unitários e de integração em C# utilizando xUnit com banco de dados SQL Server.

## 🛠️ Stack Tecnológica
- **Linguagem**: C# (.NET 6+)
- **Test Framework**: xUnit
- **Banco de Dados**: SQL Server

## 📌 Funcionalidades Testadas
✅ **Testes Unitários**  
- Lógica de negócio isolada  
- Mocking de dependências  

✅ **Testes de Integração**  
- Operações CRUD com SQL Server  
- Testes transacionais (rollback automático)  

✅ **Testes de Schema**  
- Validação de estrutura do banco  

## 🚀 Como Executar

### Pré-requisitos
- .NET 6 SDK
- SQL Server
